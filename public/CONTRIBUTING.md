# Contributing to Conduit

Thanks for helping! Conduit is developed by [MorphEdit](https://github.com/MorphEdit). The program's
source code is private, so this repository holds the documentation, examples and releases.

## What you can send as a pull request

- Fixes and improvements to the documentation (English or Thai)
- New or better examples (docker-compose files, deployment guides, scripts)
- Translations

Please keep pull requests small and focused, and describe what you changed and why.
By opening a pull request you agree that your contribution may be used under the [LICENSE](LICENSE)
(section 5).

## Reporting bugs and asking for features

Open an [issue](https://github.com/MorphEdit/conduit/issues/new/choose) and use the template.
The most useful bug reports include:

- `conduit version` output
- PostgreSQL version and how you run Conduit (binary, Docker, OS)
- What you did, what you expected, what happened
- The relevant lines of the Conduit log (remove passwords and invite codes first)
- A screenshot of the dashboard if it helps

## Security issues

Please do **not** open a public issue — see [SECURITY.md](SECURITY.md).

# การมีส่วนร่วม (ภาษาไทย)

ขอบคุณที่ช่วยครับ Conduit พัฒนาโดย [MorphEdit](https://github.com/MorphEdit) ตัว source code เป็นแบบส่วนตัว
repo นี้จึงมีแค่คู่มือ ตัวอย่าง และไฟล์โปรแกรมให้ดาวน์โหลด

- **ส่ง pull request ได้:** แก้หรือเพิ่มคู่มือ (ไทย/อังกฤษ), ตัวอย่างการติดตั้ง, คำแปล
- **เจอบั๊กหรืออยากได้ฟีเจอร์:** เปิด [issue](https://github.com/MorphEdit/conduit/issues/new/choose) ตามแบบฟอร์ม
  แนบผลของ `conduit version` เวอร์ชัน Postgres และ log ที่เกี่ยวข้อง (ลบรหัสผ่านกับรหัสเชิญออกก่อน)
- **ปัญหาด้านความปลอดภัย:** อย่าเปิด issue สาธารณะ ดู [SECURITY.md](SECURITY.md)
